# 🏢 Ethiopian House Rental Platform

> Unified platform architecture containing web, mobile, and backend applications for Ethiopian property rentals, 3D spatial tours, and Chapa payment integration.

## 📂 Architecture Overview

```text
Ethiopian-House-Rental/
├── backend/   # Backend APIs and database service configuration
├── mobile/    # Flutter mobile application for iOS & Android
└── web/       # Next.js 15 web platform with 3D virtual tours & Chapa escrow
```

## 🚀 Projects

- **[Web Platform](web/)**: Built with Next.js 15, TypeScript, Tailwind CSS, Three.js, and Prisma.
- **[Mobile Application](mobile/)**: Cross-platform Flutter mobile application.
- **[Backend](backend/)**: Backend services and database integrations.
